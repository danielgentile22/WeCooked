# API fixtures

Generated by the server tests. Do not edit by hand.

`server/src/routes/api/v1/api.test.ts` exercises every `/api/v1` endpoint against a temporary SQLite database and writes each reply body here, one file per endpoint and state. Ids, timestamps, the session token and the presigned image URLs are fixed, so the files only change when a reply's shape or content changes. Keys are sorted and indented with 2 spaces.

To regenerate, from `server/`:

```sh
npm test
```

The Swift decoding tests in `WeCookedKit` read these files, so a server change that breaks a Swift model fails there.
